# Particle Suppresor

 [![Join our discord!](https://media.forgecdn.net/attachments/description/1448257/description_c5e501e5-328a-46c7-a594-bb0c451254a5.png)](https://discord.gg/xTeHR2tdYh)

If your game starts turning into a cloud of particles every time you open a machine, swing a weapon, or run a farm, this mod is for you.

Particle Suppresor gives you a simple way to tone particles down without killing them completely. You choose what gets through, and how much.

## What it feels like

Most of the time, you only need a few quick adjustments:

1. Lower the particles that are getting in the way
2. Leave the ones you still want to see
3. Put stronger rules near a specific spot if one area is especially noisy

The result is a cleaner screen, better visibility, and less visual clutter while you play.
